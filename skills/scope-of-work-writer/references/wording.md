# Wording guide

The linter flags these phrases because each one hides a decision.

| Vague | Better |
|---|---|
| Patch drywall as needed | Patch up to 3 drywall holes, each under 6 in across, on the north wall |
| Paint walls, trim, etc. | Paint walls and baseboard, two coats. Ceiling and door not included |
| Fixtures TBD | Faucet: $180 allowance, owner selects by the start date |
| Standard grade tile | Porcelain floor tile, 12 x 24 in, from the allowance below |
| Repair subfloor if necessary | Subfloor repair is excluded. If damage is found it is priced by change order |
| Miscellaneous plumbing | Replace 2 supply stops and 1 P trap at the vanity |

Rules of thumb:

- Name the location, the material and the extent in every inclusion.
- Give a number wherever a number exists: count, square feet, linear feet, coats.
- Say who supplies each product and who hauls away debris.
- If a thing is uncertain, make it an allowance or an assumption, not a soft verb.
