# Reason codes

Open the "Reason for change" paragraph with one of these so changes can be counted later.

| Code | Use when | Typical evidence |
|---|---|---|
| Owner request | The owner asked for something not in the scope | dated message or meeting note |
| Concealed condition | Something hidden was found after demolition | photos before and after opening |
| Selection change | A chosen product was swapped or discontinued | product sheets for both |
| Code or inspection | An inspector required work outside the scope | inspection note |
| Scope correction | The scope missed or double counted an item | scope section reference |

Write the reason as: code, what was found or asked, where, and which scope section it
amends. One short paragraph. No blame.
